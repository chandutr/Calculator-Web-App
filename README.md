# 🧮 Calculator Web App

A simple and interactive calculator web application built using **Python Flask, HTML, CSS, and JavaScript**.

## 📌 Project Description

This project is a web-based calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

The frontend is developed using HTML and CSS, while JavaScript handles user interactions and updates the calculator display. Flask is used as the backend to process the mathematical expression and return the result.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Clear button
- Interactive calculator interface
- Flask backend
- HTML/CSS/JavaScript frontend

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Jinja2
